# Social-card fonts

These build-only font files make Atlas social-card typography independent
of fonts installed on the machine running the generator.

- `SourceSans3-Bold.ttf` and `SourceSans3-Black.ttf` come from
  [`adobe-fonts/source-sans`](https://github.com/adobe-fonts/source-sans) at
  commit `87b37a2daaed80fcb8e8ccb0085c4d72ddade12e`.
- `SourceSerif4-Black.ttf` comes from
  [`adobe-fonts/source-serif`](https://github.com/adobe-fonts/source-serif) at
  commit `5f220b17d27ed64873f22cde0dd593685387bd19`.

All three files are distributed under the SIL Open Font License 1.1; see
`LICENSE.md`. They are registered with private Atlas family names by the
generator and are not shipped as web fonts.
